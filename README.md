# Car Shop

Самостоятельное учебное приложение React + TypeScript + Vite для существующего REST API. Создание, редактирование, удаление, поиск по шести полям, сортировка и адаптивный интерфейс. Интерфейс на английском, как в задании; учебные пояснения на русском.

## Начните здесь

1. Установите Node.js 24 LTS (или Node >= 22.12). В Terminal на macOS откройте распакованную папку проекта: `cd `, затем перетащите папку в Terminal и нажмите Enter.
2. Выполните `npm ci`.
3. Для безопасной практики запустите `npm run mock` в первом Terminal. Во втором, в той же папке: `VITE_API_BASE_URL=http://127.0.0.1:4174/ npm run dev`. Откройте напечатанный адрес (обычно http://127.0.0.1:5173).
4. Добавьте машину, найдите её, измените, затем удалите с подтверждением. Локальные данные хранятся только в памяти; перезапуск mock восстанавливает два примера.
5. Прочитайте [условие без решения](docs/ASSIGNMENT.md), затем [полную пошаговую инструкцию и листинги](docs/MANUAL.md). Результаты и границы проверки: [VERIFICATION](docs/VERIFICATION.md).

## Подключение к учебному API

Без переменных приложение подключается к https://car-rest-service-carshop.2.rahtiapp.fi/. Для другого сервера выполните `cp .env.example .env`, измените `VITE_API_BASE_URL` и перезапустите Vite. `.env` не включается в архив. Переменные `VITE_*` публичны, в них нельзя хранить пароли.

Общий сервер используется другими студентами. Add/Edit/Delete меняют его данные; для упражнений и автотестов используйте mock. В комплекте нет вызова reset. При потере связи во время сохранения сначала обновите список: запрос мог успеть выполниться.

## Проверка

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E автоматически запускает отдельные локальные серверы на 4174 и 4175. Перед тестом завершите свой `npm run mock`; тесты не переиспользуют чужой сервер. `npm run check:live` выполняет только GET и записывает обезличенный протокол. `npm run preview` показывает собранное приложение; для обычной работы используется `npm run dev`.

## Состав

- `src/` — всё приложение, типы, API, валидация и стили.
- `tests/` — контрактные и браузерные проверки.
- `scripts/` — локальный mock, GET-проверка, генерация полного руководства и упаковка.
- `docs/` — отдельное условие, инструкция, протокол и упражнения с отдельными решениями.
- `tests/` и команды выше позволяют воспроизвести проверки самостоятельно; локальные отчёты не публикуются.

Переносимый архив создаёт `npm run package` на Windows, используя штатный PowerShell. Запуск/сборка/тесты приложения переносимы на macOS. Для запуска через общее меню выполните `bash ./build-and-run.sh`. Скрипт установит зависимости, выполнит проверки, соберёт и запустит приложение.

## Единый запуск

```sh
bash ./build-and-run.sh
```

Для автоматической проверки сборки и HTTP с остановкой сервера: `bash ./build-and-run.sh --smoke-test --no-open`. [Перенос в свой GitHub](docs/CLIENT-HANDOFF.md).
