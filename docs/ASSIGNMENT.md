# Car Shop — задание

Источник: предоставленное условие Car Shop, 14 октября 2026. Самостоятельное задание по React.

Разработайте front end для существующего REST backend магазина автомобилей. Магазин должен управлять своим запасом машин.

Обязательные возможности:

1. Add, Delete и Edit автомобилей.
2. Поиск и сортировка.
3. Удобный адаптивный пользовательский интерфейс.

Используйте поля `brand`, `model`, `color`, `fuel`, `modelYear`, `price`. Пример на скриншоте содержит таблицу автомобилей и диалог добавления/редактирования.

Документация: https://juhahinkula.github.io/carshopdocs/ и https://juhahinkula.github.io/carshopdocs/cars/. React Query для сетевых запросов разрешён, но не обязателен. Backend уже существует; писать новый производственный backend не требуется.

Проверьте создание, редактирование и удаление; поиск существующей и отсутствующей записи; сортировку чисел и текста; поведение на широком и узком экране. Проверьте отображение загрузки и ошибок. Для автоматических изменений используйте отдельную локальную тестовую среду, не общую базу курса.

Этот файл содержит условие и критерии самостоятельной проверки; код решения находится отдельно.
