# Практика без ответов

1. Запустите приложение с локальным mock. Создайте машину с десятичной ценой и найдите её по цвету. Какую строку поиска можно использовать для поиска по году?
2. Создайте две машины с ценами 9 и 100. Объясните ожидаемый порядок при сортировке по возрастанию и убыванию.
3. Попробуйте сохранить пустую форму, отрицательную цену и дробный год. Запишите, какое поле получает фокус и что сообщает интерфейс.
4. Откройте редактирование. Измените модель и нажмите Cancel. Сравните данные до и после.
5. Откройте удаление. Нажмите Escape. Затем повторите удаление и подтвердите действие.
6. В DevTools найдите запрос POST. Назовите URL, Content-Type, шесть полей и типы числовых значений. Не подключайте общий backend для этого упражнения.
7. Объясните, почему id нельзя заменить индексом строки после сортировки. Как определить id, если сервер возвращает только HAL-ссылки?
8. Остановите mock и нажмите Refresh. Что осталось в таблице? Как вернуть связь и повторить загрузку?
9. Проверьте форму при ширине 390px и при управлении с клавиатуры. Найдите способы закрыть форму без сохранения.
10. Объясните разницу между GET-проверкой общего API и проверкой POST/PUT/DELETE на тестовом сервере. Какие результаты не доказывают, что реальные remote mutations уже проверены?
