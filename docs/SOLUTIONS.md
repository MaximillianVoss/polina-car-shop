# Ответы к практике

1. Поиск проверяет текстовое представление всех шести полей. `2024` найдёт записи с таким годом, а также совпадения в других полях. Регистр и пробелы по краям запроса игнорируются.
2. Ascending: 9, затем 100. Descending: 100, затем 9. Числа сравниваются вычитанием; строковое сравнение дало бы неправильный результат. Строки сравниваются localeCompare с нечувствительностью к регистру.
3. Пустые текстовые поля отклоняются; обязательны год и цена. Год — целое число 1886…текущий год+1, цена — конечное число 0…10^12. Это явная политика клиентской валидации, а не дополнительное требование преподавателя. Первое ошибочное поле получает фокус, у ошибки есть связь aria-describedby.
4. Форма хранит копию данных в draft. Cancel удаляет эту форму из дерева React, запрос PUT не отправляется. Данные таблицы остаются прежними.
5. Нативный dialog поддерживает Escape и удерживает фокус внутри. Удаление выполняется только кнопкой Delete car. Cancel получает начальный фокус в подтверждении. На время запроса закрытие и повторные действия блокируются.
6. Локальный POST направлен на http://127.0.0.1:4174/cars, Content-Type application/json. Тело содержит только brand/model/color/fuel (string) и modelYear/price (number). В тело не попадают id, _links и внутреннее состояние формы.
7. Индекс меняется при фильтрации, сортировке и удалении. id постоянен. API извлекает последний числовой сегмент pathname из self.href, с fallback на car.href или числовой id. Hostname из HAL не используется для PUT/DELETE: адрес строится на настроенном base.
8. Ошибка отображается отдельно, ранее полученные данные остаются в кеше. После запуска `npm run mock` нажмите Try again/Refresh. Mock начинает с двух исходных машин; это тестовая память, не persistent DB. Первичная ошибка без кеша показывает сообщение без ложного пустого состояния.
9. Мобильные строки отображаются карточками, поля формы — одним столбцом. Форма прокручивается при малой высоте. Cancel и Escape отменяют ввод, фокус возвращается к открывшей кнопке. Tab перемещается по доступным контролам внутри dialog.
10. GET подтверждает доступность и формат чтения. Локальные POST/PUT/DELETE проверяют контракт клиента и UI, но не текущие разрешения и запись реального сервера. В протоколе remote mutations стоят как не проверенные; зелёная сборка не меняет этот статус.
