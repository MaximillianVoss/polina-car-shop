# Проверка Car Shop 1.1 — автоматический локальный mock

Дата: 16 октября 2026. По запросу пользователя добавлен автоматический переход на локальные тестовые данные при недоступном API.

## Поведение

При обычном запуске Vite dev/preview сначала используется настроенный REST API через существующий локальный proxy. Если GET списка завершается сетевой ошибкой, HTTP 5xx либо не завершается за 8 секунд, включается встроенный mock в памяти вкладки. Отдельный процесс npm run mock не нужен. Вверху появляется жёлтый баннер LOCAL DEMO. В локальном наборе Volvo XC60 и Nissan Micra; доступны Add/Edit/Delete, поиск и сортировка.

Режим закреплён до перезагрузки страницы; Refresh читает локальные данные. Перезагрузка заново пробует API и сбрасывает локальные правки. Ошибка remote POST/PUT/DELETE не переключает режим и не повторяет операцию. Локальные данные никогда не отправляются на общий сервер. ID имеют отдельное пространство demo-N. Ошибки 4xx, неправильный JSON и нарушения HAL-схемы показываются явно.

## Подтверждения

Среда: Windows, Node.js 24, Chromium/Playwright.

| Проверка | Результат |
|---|---|
| TypeScript и production build | Успешно |
| Unit: API, connection, model, fallback | 38/38 |
| Браузерные сценарии | 7/7 |
| Переход при HTTP 503, обрыве сети и зависшем GET | Проверен; тайм-аут 8 секунд |
| Локальные create/edit/delete/refresh | Проверены; после перехода новых HTTP mutation нет |
| Возврат к доступному API после reload | На локальном HTTP test double |
| Отказ для remote ID в demo, изоляция наборов | Unit |
| Параллельные GET: поздний remote ответ не возвращает remote rows при активном demo | Unit |
| Узкий экран 390×844 | Скриншот evidence/auto-fallback-mobile.png просмотрен |

Независимая проверка выявила гонку двух одновременных чтений: поздний remote ответ мог вернуться после включения demo первым запросом. После await повторно проверяется выбранный режим; добавлен воспроизводящий тест. Remote mutation не повторяются и не перенаправляются при ошибке.

Архив проверяется из отдельной распакованной папки: SHA-256 вложений сверяются с evidence/package-manifest.json; выполняются сборка и unit/браузерные сценарии. Внешняя квитанция delivery/extracted-verification.json относится к окончательному ZIP. В ZIP нет node_modules, dist, .git, рабочих .env и временных распакованных копий.

## Ограничения

- Недоступность API смоделирована контролируемыми отказами. Remote mutations не выполнялись; общая база не сбрасывалась.
- Живое чтение общего сервера для изменения не перепроверялось; HTTP 200 от 14 октября не считается подтверждением сегодняшней доступности.
- Настоящий Mac клиента не проверялся. Инструкция содержит команды macOS, фактические тесты выполнены на Windows.
- Демо хранится в памяти вкладки и сбрасывается при reload. Это тестовые данные, не offline-копия общей базы.
- Публикационная копия сохраняет существующие общие build-and-run.sh/export-project.sh. Каталог скачивает ветку main этого репозитория; изменение общего меню не требуется.
