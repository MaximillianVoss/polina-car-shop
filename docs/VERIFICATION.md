# Car Shop — проверка и ограничения

Исходная версия проверена 14 октября 2026 на Windows: typecheck, production build,
16 unit и 5 браузерных тестов. CRUD проверялся только на локальном HTTP mock.
Публичная копия содержит исходники и тесты для самостоятельного повторения.
Локальные отчёты, пути компьютера исполнителя и прежние ZIP-квитанции не публикуются.

```sh
npm ci
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Сквозная проверка загрузчика: `bash ./build-and-run.sh --smoke-test --no-open`.
Для ручного CRUD используйте `npm run mock` и во втором терминале
`VITE_API_BASE_URL=http://127.0.0.1:4174/ npm run dev`.
E2E самостоятельно запускает mock; порты 4174 и 4175 должны быть свободны.

| Требование | Готово | Как проверить | Ограничения |
|---|---|---|---|
| React/TypeScript/Vite и REST API | Да | typecheck, build, API tests | Для внешнего API нужна сеть |
| List/Add/Edit/Delete | Да | 16 unit и 5 E2E на локальном mock | Remote POST/PUT/DELETE не проверялись |
| Поиск, числовая сортировка, формы | Да | unit и E2E | Поиск по загруженной коллекции |
| Ошибки, загрузка, подтверждение удаления | Да | E2E HTTP failures и восстановление | Сетевые сбои моделируются |
| Адаптивный UI и управление фокусом | Да | E2E, viewport 390px | Отдельный screen reader аудит не выполнялся |
| Условие, руководство, практика и решения | Да | docs/ и полные листинги MANUAL | Фактический запуск на macOS не выполнялся |

Предыдущая read-only проверка общего API выполнила только GET /cars (HTTP 200).
Это не подтверждает текущие права записи на общий сервер. Mock хранит данные
в памяти; перезапуск восстанавливает примеры. Валюта backend не установлена.
Переменные VITE_* публичны и не предназначены для секретов.
